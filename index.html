Agent mission system

From brief to shipped.

Aegis turns your coding agent into an accountable product team. It plans, builds, secures, tests, commits, deploys, and verifies the live result — and it is incapable of pretending any of those steps happened.

Install Aegis./verify.sh

The execution loop every mission follows

  1. MISSION
  2. STATE
  3. EXECUTE
  4. EVIDENCE
  5. CHECKPOINT
  6. RESUME
  7. VERIFY
  8. SHIP

Built on verifiable behavior

Most agent scaffolding optimizes for impressive output. Aegis optimizes for outcomes you can trust, at the lowest honest cost.

Honest verification

Every worker is probed before it can appear active. No simulated reviews, phantom tests, or claimed deployments — evidence or it did not happen.

Usage governance

A deterministic governor routes each pass to the cheapest capable route, batches inspection, and stops the moment acceptance evidence passes.

Durable mission state

Mission, state, and log files capture decisions and proof as work happens, so any session resumes without rediscovering the world.

Security-first authority

Least privilege by default, validation at every trust boundary, and hard stops before money, irreversible actions, or sensitive external sends.

Six focused components

Each skill owns one job completely. Together they cover the full delivery lifecycle; apart, each is useful on its own.

The mission operating system: versioned state, evidence gates that refuse unevidenced completion (re-executable evidence), git-aware staleness, checksummed checkpoints, one-command resume, and regression memory that auto-surfaces past failures when you touch related code. Stdlib-only.

Install in one minute

Skills are plain Markdown plus deterministic scripts — no daemon, no account, no telemetry. From the repository root:

1 · Get the code
git clone https://github.com/abobaker288882-crypto/aegis.git
2 · Install (safe & reversible)
./install.sh
3 · Verify everything
./verify.sh
Manual alternative
cp -R aegis-ceo-skills usage-optimizer second-brain-context five-year-old ~/.agents/skills/
  • The installer is idempotent, backs up existing copies before upgrading, and ends with a live smoke check — see QUICKSTART.md.
  • Python 3.9+ powers the deterministic helpers — stdlib only, no packages to install.
  • External model workers are optional and always verified with a real capability probe before they are used or shown active.
  • This site: Next.js 16, statically delivered, zero third-party origins.
